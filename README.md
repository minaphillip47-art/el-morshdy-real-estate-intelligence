## 🏢 Project Overview

El Morshdy is a real estate collection intelligence dashboard
designed to provide management with a centralized view of
collection performance across multiple real estate projects.

## 🎯 Business Problem

The project addresses the challenge of monitoring installment
collections across multiple projects, payment methods and banks.

## 🎯 Analytical Objectives

- Monitor collection performance
- Compare projects
- Analyze collection by date
- Analyze Cash customers
- Analyze Bank-financed customers
- Compare performance by bank

## 🛠️ Tools

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization
